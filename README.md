# ShopSync - Frontend UI Project

Dự án được chuyển đổi từ bản thiết kế **Figma** sang **HTML, CSS (BEM), và JavaScript**.  
Đây là bài tập nhóm cho môn **Thiết kế Web**.

## 👥 Thành viên nhóm
- Nguyễn Nhật Minh
- Đỗ Khắc Hậu

## 📌 Mô tả dự án
- Chuyển đổi giao diện từ thiết kế Figma sang mã nguồn tĩnh.
- Sử dụng phương pháp đặt tên theo chuẩn **BEM (Block - Element - Modifier)**.
- Tối ưu cho khả năng **responsive** trên màn hình desktop và mobile.
- Tích hợp JavaScript cho các phần tương tác cơ bản (menu, slider, v.v.).

## 🛠 Công nghệ sử dụng
- **HTML5**
- **CSS3 (BEM)**
- **JavaScript**
- **Figma** (tham khảo thiết kế)
